# Path exclusions: a line starting with "!" carves a specific path out of an
# otherwise-authorized domain/wildcard, e.g. a bug-bounty program that
# authorizes the whole domain but explicitly excludes a whistleblowing or
# legal-reporting endpoint. The domain part matches like an ordinary scope
# entry (exact host or any subdomain); the path part is a glob ("*" also
# matches "/", so a broader glob only ever excludes more, never less).
# An exclusion always wins over any positive match, even a wildcard.
*.bancoplata.mx
*.platacard.mx
!bancoplata.mx/*/whistleblowing
!platacard.mx/*/whistleblowing
